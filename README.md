
# Só Jogo Moz

Este é o site de apostas Só Jogo Moz, com registro por número de telefone e suporte para depósitos manuais via M-Pesa e e-Mola.

## Como rodar

1. Instale as dependências:
```
npm install
```

2. Crie um arquivo `.env.local` com a string de conexão MongoDB:
```
MONGODB_URI=...
```

3. Rode o servidor:
```
npm run dev
```
